# Changelog

All notable changes to **LX Split Aim**.

## v1.0.0

First public release on the Steam Workshop and GitHub.

### Changed in this version

- Russian translation added (EN/ES/AR/RU).

### Included

- Shoot zombies on the ground
- Every player gets their own aim
- B41-style lock-on
- Soft-snap when nothing is locked
- Stays out of the way
